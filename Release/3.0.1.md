## Engineering notes

- Volume entry uses millilitres as its source of truth. Presets populate the numeric field; custom input overrides them. Supported volumes are whole numbers from 1 to 32767 ml.
- Reject empty names, invalid or nonpositive prices, and invalid volumes. Show localized persistence errors and keep the editor open when saving fails.
- Sort best-value calculations explicitly and break equal-price ties by persistent object ID. Refresh highlighted details and savings together, including when the winning object remains the same.
- Refresh widget data after successful mutations and when the main app becomes active. Normal widget snapshots read saved data. Comparisons still require at least two beers.
- Disable widget writes from the App Clip, which has its own database and no widget App Group entitlement.
- Resolve Core Data entities from the injected context. Support in-memory deletion for previews and isolated SQLite fixtures for persistence tests.
- Set the app, App Clip, and widget to version 3.0.1, build 44.

## Validation and remaining checks

- The regression suite passed: 45 tests, zero failures. Coverage includes volume handling, validation, ranking, highlight refresh, SQLite CRUD and reopening, rollback, and widget data updates.
- Signed archiving and local App Store IPA export succeeded during release preparation.
- Manual UI and on-device widget refresh verification remain outstanding; Computer Use permissions were unavailable.
- The Google SDK placeholder binaries triggered symbol-upload warnings during the original export. A separate local export skipped symbol upload as a workaround, with real dSYMs preserved separately. This does not supply symbols for the placeholders and limits Apple's automatic crash symbolication. No export workaround configuration is included in this commit.
