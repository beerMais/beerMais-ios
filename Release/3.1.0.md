# Beer Mais 3.1.0 (47)

## Português — notas para a App Store

- Nova tela para adicionar e editar bebidas, com preço em destaque e comparação por litro em tempo real.
- Digite os números do preço e os centavos são preenchidos automaticamente.
- Correção do teclado ao digitar preços e opção de fechá-lo ao tocar fora dos campos.
- Melhor adaptação dos anúncios à largura e à altura disponíveis.

- Confirmação antes de excluir uma bebida e melhorias nas traduções.

## Release scope

- App, widget, and App Clip: marketing version 3.1.0, build 47, in Debug and Release. Test bundle version unchanged. Supersedes the earlier build 45 and 46 candidates.
- Keep existing Core Data schema and stored prices/volumes; no migration is introduced.
- Price input is a cents keypad: `1 → 0,01`, `2 → 0,12`, `5 → 1,25`, `0 → 12,50`. Commas match the existing BRL display. Digit-based pastes follow the same cents interpretation.
- Preserve custom volumes (1–32767 ml), error handling, keyboard dismissal, destructive-action confirmation, and the main floating sheet.
- Add/Save stays in the top toolbar. The ad area remains in the editor.
- UIKit price-field focus is kept separately from SwiftUI volume/brand focus. Typing and backspace preserve the price keyboard; tapping outside inputs and the existing OK/preset actions dismiss it.
- Scrolling ad placements use inline adaptive banners with a 100-point maximum requested height. The actual height follows the SDK size callback, native bounds match the requested width, and resizing replaces pending requests without clipping the creative.
- iOS 26 uses native Liquid Glass controls; older supported iOS versions use bordered controls.
