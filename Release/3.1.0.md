# Beer Mais 3.1.0 (45)

## Português — notas para a App Store

- Nova tela para adicionar e editar bebidas, com preço em destaque e comparação por litro em tempo real.
- Digite os números do preço e os centavos são preenchidos automaticamente.
- Atalhos de volume com visual Liquid Glass e suporte a volumes personalizados.
- Melhorias no alinhamento dos cartões, em telas maiores e na adaptação ao tamanho do texto.
- Confirmação antes de excluir uma bebida e melhorias nas traduções.
- Cancelar uma doação não abre mais um anúncio; assistir a um anúncio agora é uma opção separada.

## English — App Store release notes

- Redesigned drink editor with prominent price entry and a live price-per-litre preview.
- Enter price digits and the decimal places are filled automatically.
- Liquid Glass volume shortcuts with support for custom volumes.
- Improved card alignment, larger-screen layouts, and text-size adaptation.
- Confirmation before deleting a drink and improved translations.
- Cancelling a donation no longer opens an ad; watching an ad is now a separate option.

## Español — notas para la App Store

- Nueva pantalla para añadir y editar bebidas, con el precio destacado y una vista previa del precio por litro.
- Introduce los dígitos del precio y los decimales se completan automáticamente.
- Atajos de volumen con Liquid Glass y compatibilidad con volúmenes personalizados.
- Mejoras en la alineación de las tarjetas, las pantallas grandes y la adaptación al tamaño del texto.
- Confirmación antes de eliminar una bebida y mejoras en las traducciones.
- Cancelar una donación ya no abre un anuncio; ver un anuncio es ahora una opción independiente.

## Release scope

- App, widget, and App Clip: marketing version 3.1.0, build 45, in Debug and Release. Test bundle version unchanged.
- Keep existing Core Data schema and stored prices/volumes; no migration is introduced.
- Price input is a cents keypad: `1 → 0,01`, `2 → 0,12`, `5 → 1,25`, `0 → 12,50`. Commas match the existing BRL display. Digit-based pastes follow the same cents interpretation.
- Preserve custom volumes (1–32767 ml), error handling, keyboard dismissal, destructive-action confirmation, and the main floating sheet.
- Add/Save stays in the top toolbar. The ad area remains in the editor.
- iOS 26 uses native Liquid Glass controls; older supported iOS versions use bordered controls.
