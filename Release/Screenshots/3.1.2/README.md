# iPhone Duo App Store screenshots

Two promotional screenshots for the 3.1.2 App Store draft:

- `beer-mais-duo-inner-2853x2007.png`: landscape inner-display comparison layout.
- `beer-mais-duo-outer-1398x2034.png`: portrait outer-display two-column layout.

Visual reference: the existing Beer Mais App Store campaign, with charcoal background, white/gold Portuguese headlines and a beer-wave footer. AI-assisted promotional artwork uses the verified real Duo layout captures from this session as references. The light app UI, rankings, prices and volumes were visually checked against those captures. These are marketing composites, not pixel-identical simulator exports. `duo-background.png` is the generated artwork source.

Both final PNGs have no alpha and match dimensions explicitly accepted by the iPhone Duo slot in App Store Connect. Apple accepted both uploads in Portuguese (Brazil); English (U.S.) and Spanish (Mexico) inherit the same pair via Using Existing Assets, matching the existing campaign's localization approach. Existing conventional-iPhone screenshots were preserved.

A fresh simulator capture attempt hit Data Migration Failed twice; the successful earlier current-layout captures were used instead. No new binary, build, public submission or release was needed.

Verification evidence: `/tmp/beermais-duo-screenshots-en-state.txt`, `/tmp/beermais-duo-screenshots-es-state.txt`.
