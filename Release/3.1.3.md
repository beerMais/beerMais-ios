## Xcode 27.2 compatibility review

Sources: [Xcode 27.2 release notes](https://developer.apple.com/documentation/xcode-release-notes/xcode-27_2-release-notes), [iOS 27.2 release notes](https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27_2-release-notes).

- Xcode includes Swift 6.4 and iOS 27.2. The project already uses the selected SDK, so no SDK version needs hardcoding in project settings.
- Device Hub improves simulator input, Duo Standby support, and memory-warning simulation. Known Duo limitations remain: screenshots can be black shortly after boot; accessibility tools cannot convey screen content through Device Hub; modifier keys can stop working after switching displays. These require testing precautions, not speculative application changes.
- UIKit default view margins changed in iOS 27.1 and later. The app's custom UIKit price field sizes itself explicitly; adaptive banners measure their SwiftUI container. Neither depends on default layout margins. Preserve current layout pending runtime validation.
- iOS 27.2 introduces expanded tracking authorization prompts for some EU countries. No application ATT request exists in this codebase. This SDK change alone does not justify adding a tracking prompt. Ads/privacy behavior still needs device acceptance checks.
- StoreKit testing fixes concern test sessions and subscription offers. Beer Mais uses existing donation products; sandbox donation checks remain necessary.
- New JSON project format is optional. Retain the existing project format and reference-runtime CI; no migration is required for this release.
